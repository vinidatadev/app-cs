================================================================================
                     COMO FAZER DEPLOY NO PORTAINER
================================================================================

1. PREPARAÇÃO (na sua máquina):
   
   a) Testar localmente primeiro (ver acima)
   
   b) Editar .env com senhas seguras:
      POSTGRES_PASSWORD=senha_segura_producao
      SECRET_KEY=chave-jwt-minimo-32-caracteres
   
   c) Gerar TAR de deploy:
      Executar: gerar-deploy.bat
      Ou manual: tar -cf organograma-deploy.tar docker-compose.yml frontend backend database .env

2. NO PORTAINER:
   
   a) Acessar: http://ip-do-servidor:9000
   
   b) Stacks → Add Stack
   
   c) Nome: organograma
   
   d) Build method: Upload
   
   e) Selecionar: organograma-deploy.tar
   
   f) Deploy the stack
   
   g) Aguardar build (5-10 minutos)

3. VERIFICAÇÃO:
   
   a) Stacks → organograma → Ver 3 containers rodando
   
   b) Acessar: http://ip-do-servidor:3000
   
   c) Testar login e navegação

4. SE DER PROBLEMA:
   
   Ver: docs/07-TROUBLESHOOTING.md
